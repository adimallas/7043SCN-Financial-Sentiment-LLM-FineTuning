# Task 1 marking criteria — evidence map

| Criterion in brief | Weight | Concrete evidence |
|---|---:|---|
| Project setup: model, domain, dataset | 10% | `README.md`, `docs/EXPERIMENT_PROTOCOL.md`, data source hash, model card |
| Methodology: baseline, FFT, advanced approach | 10% | Colab notebook, `task1_pipeline.py`, training reports and adapter selection |
| Implementation: hardware, parameters, libraries, challenges | 10% | Runtime config, training JSON reports, loss logs and manuscript methodology |
| Reproducibility: experiment/code/viva | 10% | Notebook, source, tests, prediction files and plots; **video to be recorded** |
| Quantitative evaluation | 10% | Held-out metrics, bootstrap CIs, confusion matrices, verifier script |
| Qualitative discussion | 10% | Error breakdown, prompt sensitivity, scientific manuscript discussion |
| Real-world applicability and advancement | 5% | Intended-use boundary, efficiency analysis and discussion of robustness |
| Social, ethical, legal and professional | 5% | Dataset license, model card, deployment risks and paper section |
| Language and structure | 10% | IEEE manuscript; final PDF must be rechecked after URL insertion |
| References and visualisations | 10% | Manuscript references; logged plots; consistent figure numbering |
| Originality | 10% | Validation-selected rank ablation, uncertainty analysis, prompt wording sensitivity |

**Evidence is not a predicted mark.** The video, genuine git commit history and final university submission are external steps, not automatically accomplished by this repository.
